Лабораторна робота №5
Варіант 16 — Моделювання плавучості тіла на межі повітря/рідини

1. Вимоги:
   - Windows;
   - CMake;
   - Ninja;
   - vcpkg;
   - SFML 3;
   - Visual Studio з компонентами C++.

2. Відкрийте PowerShell у папці проєкту.

3. Перевірте, що змінна VCPKG_ROOT налаштована:
   echo $env:VCPKG_ROOT

   Якщо команда нічого не виводить, виконайте:
   $env:VCPKG_ROOT = "C:\vcpkg"

4. Сконфігуруйте проєкт:
   cmake --preset default

5. Зберіть програму:
   cmake --build --preset default

6. Запустіть:
   .\build\Lab5_Buoyancy.exe

Якщо SFML ще не встановлена через vcpkg, під час конфігурації CMake
vcpkg автоматично завантажить і збере залежність із vcpkg.json.

Керування:
- Up / Down — збільшити / зменшити густину тіла;
- Left / Right — збільшити / зменшити густину рідини;
- Space — пауза / продовжити;
- R — перезапустити моделювання;
- Також можна натискати кнопки в інтерфейсі.

Для тексту програма використовує системний шрифт Windows:
C:/Windows/Fonts/arial.ttf
